PHASE 06 — FULL FEATURE & FUNCTIONAL REPLICATION

Act as a senior full-stack application engineer.

Your task is to implement the actual functionality behind every identified module in the Aqar application.

The goal is functional parity, not merely visual similarity.

1. Listings module

Implement:

- Property listings.
- Rent and Sale categories.
- Map and List views.
- Property category filters.
- Search.
- Sorting by Latest, Price and Nearest.
- Property detail pages.
- Property images and galleries.
- Map markers and marker selection.
- Add listing/request workflow where verified.

Map and List must display synchronized data.

2. Filters and New Order

Implement:

- Age selection.

- Private roof.
- Apartment in villa.
- Two entrances.
- Special entrances.

- Near metro.

Preserve filter selections between steps.

3. Buying Requests
